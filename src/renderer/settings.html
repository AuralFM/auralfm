A nickname is not an account: nothing verifies it, and your key is different in every place you listen to. None of them are saved.

Keep one identity across sessions
Your lasting fingerprint —
Private rooms Type /hub in the chat

Type /hub “radio club” yourpassword in the chat. The same name and password is the same room. Relays cannot read it. Anyone who learns the pair can read all of it, past messages too.

Off: a new key each time, so nobody can keep or verify you. On: one saved key for private messages, and anyone watching the relays can tell it is you each time. Turning it off destroys the key.

Send error reports

Off unless you turn it on. When something breaks, it sends what broke and where in the code. Never what you play, where you are, or who you are.

Word list

Nobody moderates this network. The word filter catches careless abuse. “Only people you keep” is what really holds. Reporting mutes the sender at once.

People you keep

Sync favorites

Keeps your favorites the same on every device with the code. The list is sealed before it leaves. Anyone with the code can read and change it.

Move to a new install

The code holds your favorites, settings, mutes and contacts. Copy it here, then paste it in the new install. No account.

Erase everything now

Erases favorites, history, the mute list and this session’s keys. Appearance stays. Cannot be undone.
