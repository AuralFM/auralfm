# Security

## Report a problem

Email **hello@auralfm.xyz** with "Security" in the subject. Please do not open
a public issue for something that could be used against listeners.

Say what you found, how to see it, and which version or address it was on.
This is one maintainer: every report is read and answered, and a fix can take
time. You will be told where it stands.

There is no bounty.

## What counts

- Anything that reveals where a listener is, what they hear, or who they are.
- Anything that lets one listener act as another, or read a private message.
- Anything that makes the app load or run code it did not ship with.
- A secret in a published file.

## What is already known

`docs/LEGAL-AND-SECURITY.md` lists what was checked and what is still open,
including the one thing that cannot be fixed from here: the shortwave receiver
list is only served over plain http.

## Supported versions

The web player at listen.auralfm.xyz is always the latest. The Mac app is in
beta; only the newest build is fixed.
