# Governance

AuralFM is led by its founder, Melton Bell III ([@meltonbell3](https://github.com/meltonbell3)).

- **Decisions.** The project lead decides what goes in, and says why in the
  issue or pull request.
- **Changes.** Every change is reviewed by a code owner ([CODEOWNERS](CODEOWNERS))
  and must pass `npm run audit`.
- **Direction.** Open an issue to propose something. Small fixes can go
  straight to a pull request.
- **Conduct.** The [Code of Conduct](docs/CODE-OF-CONDUCT.md) applies here as
  it does in the app.
- **Security.** Do not open a public issue for a vulnerability. Write to
  hello@auralfm.xyz.

This will change as more people take part.
